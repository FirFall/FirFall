Installing it

  1. Tap Download the APK. The file saves to your Downloads folder.
  2. Open it. Android will ask which app should handle it - choose Package Installer, or just tap the downloaded file.
  3. Android will warn that the app comes from outside the Play Store. Tap Settings and turn on Install unknown apps for whichever app you opened the file with (your browser, or Files). Then go back and confirm the install.
  4. That permission is per-app, and it is the only thing this page asks you to change.

Updating later

Every time the app opens it asks the server which build is current. If the one on your phone is out of date the app stops and offers you the update before you can use it, so you are never silently on a build the server has moved past. Updates are the same APK file, installed over the old one.

If the button does nothing, you downloaded a stale copy: close it, clear the browser's download and try again. The version and size above are read from the server each time you load this page.

What it asks for

Two permissions, only when you use them

  • Camera - only when you record an ember. Picking an existing clip from your gallery does not need it.
  • Microphone - only to record sound with a clip.
  • Internet - that is the whole app; it talks to the same FirFall API the website uses.

Decline either permission and the rest of the app keeps working - you just cannot record a clip with sound, or at all.

Where it comes from

FirFall is a small self-hosted project. The APK in this page is the build this repository produces, signed with the project's release key, and it is the same code the website serves. Read the Privacy Policy for what it stores and what it does not.
